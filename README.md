Welcome to the MaanyaOS Licensing Repository.

This repository contains the licensing architecture, ownership declarations, third-party notices, component boundaries, and legal documentation governing the MaanyaOS project.

MaanyaOS combines original MaanyaOS technology with software and technologies developed by other projects and organizations. These components do not automatically share the same license.

This repository exists to make those boundaries explicit.

MaanyaOS compatibility technology does not authorize software piracy.

- License-key bypassing

- Unauthorized redistribution of proprietary software
- Circumvention of legitimate licensing controls

🗂️ Why Multiple Licenses?

MaanyaOS is a large technical project.

Different components can have different:

- Ownership
- Copyright
- Dependencies
- Upstream licenses
- Distribution conditions
- Security requirements
- Compatibility boundaries
- Intended uses
- Confidentiality requirements
- Commercial requirements

Therefore, MaanyaOS does not treat every file and component as though it were automatically governed by one identical licensing rule.

The licensing suite exists to document those distinctions.

The principle is simple:

One project does not necessarily mean one license.
